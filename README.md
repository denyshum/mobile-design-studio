# MobileVision

Адаптивний вебсайт студії дизайну мобільних застосунків. Тут можна переглянути роботи й послуги, познайомитися з командою, знайти вакансію та надіслати звернення щодо проєкту.

[Відкрити сайт](https://denyshum.github.io/mobile-design-studio/)

## Основні можливості

- Пошук проєктів за назвою й коротким описом, вибір напряму, алфавітне сортування та скидання параметрів.
- Окремі сторінки проєктів і перегляд обкладинки у збільшеному вигляді.
- Форма звернення з перевіркою полів і серверним збереженням. Підтвердження відображається після відповіді сервера.
- Створення, редагування, публікація та видалення проєктів і вакансій у закритій частині.
- Завантаження обкладинок, зміна порядку записів і складу добірок на головній.
- Перегляд звернень, пошук, фільтрація, сортування та зміна їхніх статусів.

Реєстрація створює обліковий запис. Доступ до керування даними надається окремо користувачам із правами редактора.

## Технології

Клієнтська частина — HTML, CSS і JavaScript з ES-модулями. Для каруселі використано Swiper, для типографіки — Inter.

Дані зберігаються в PostgreSQL на Supabase. Supabase Auth відповідає за авторизацію, Storage — за обкладинки, Edge Functions — за серверну обробку звернень і захищені операції редактора. Клієнт звертається до розгорнутого API.

Сайт опубліковано на GitHub Pages.

## Локальний перегляд

1. Завантажте репозиторій або клонуйте його:

   ~~~sh
   git clone https://github.com/denyshum/mobile-design-studio.git
   cd mobile-design-studio
   ~~~

2. Запустіть HTTP-сервер статичних файлів у корені каталогу та відкрийте його адресу в браузері. Початкова сторінка — `index.html`. Збірка клієнта не потрібна.

Для ES-модулів потрібен HTTP-сервер. Дані, авторизація, Swiper і шрифт потребують доступу до інтернету. Підключення до хмарного API налаштоване в `assets/js/data/config.js`; локальна копія клієнта використовує цей самий сервіс.

## Структура

- `*.html` — сторінки вебсайту.
- `assets/css/` — спільні та сторінкові стилі.
- `assets/js/pages/` — поведінка окремих сторінок.
- `assets/js/components/` — спільні компоненти інтерфейсу.
- `assets/js/data/` — отримання даних і взаємодія з API.
- `assets/images/` — зображення та SVG-іконки.
- `assets/vendor/` — локальні сторонні бібліотеки.
