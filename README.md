# MobileVision

Сайт студії дизайну мобільних застосунків українською мовою.

[Відкрити сайт](https://denyshum.github.io/mobile-design-studio/)

Головна містить приклади проєктів, послуги, інформацію про команду та контакти. На вузьких екранах доступне розкривне меню; приклади робіт можна переглядати у слайдері.

## Структура

- index.html — головна сторінка.
- assets/css/ — стилі та змінні кольорів.
- assets/js/ — поведінка меню, вкладок, слайдера та прокрутки.
- assets/images/ — зображення й SVG-іконки.

Для локального перегляду відкрийте каталог сайту через HTTP-сервер статичних файлів. Swiper та Inter підключаються із зовнішніх джерел і потребують доступу до інтернету.
